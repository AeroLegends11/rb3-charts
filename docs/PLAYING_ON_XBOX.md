# Playing on Xbox 360

## What this tool creates

After successful packaging, RB3 Charts creates an Xbox 360 Rock Band 3 custom
song package (a `.con` file) inside the song run's `rb3` folder. Click
**Open output folder** to find your run. The package contains the draft you
reviewed; packaging does not automatically fix musical mistakes.

This tool does not install songs on a console, configure USB storage, change
game updates or verify your console setup. It does not create an official
store purchase and does not target Xbox One, Series X/S or Rock Band 4.

## Check your setup first

You need an Xbox 360 Rock Band 3 setup that supports customs. Not every game
edition or update configuration accepts them. Verify compatibility and use
current instructions for your specific setup from a trusted Rock Band customs
community before transferring files. A detailed transfer procedure is not
included here because it depends on that setup and has not been verified by
this project.

Do not change console settings or delete existing songs just to try a package.
Back up saves and existing custom files, and use only music and charts you have
permission to use or share.

## Review and playtest are different

A package compiling successfully only establishes that the packaging tools
accepted it. Listening review checks whether notes follow the music.
Playing on the actual console is still necessary to check loading, timing,
controller playability and difficulty reductions.

Start with one reviewed song. If it fails to load, retain the original output
and packaging logs; do not assume that changing the chart will fix a console
compatibility problem. If it loads but the notes feel wrong, record the
instrument, difficulty and song timestamp for a focused review.
